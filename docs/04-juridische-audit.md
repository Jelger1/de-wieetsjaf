# 04 · Juridische audit website

> **Geen juridisch advies.** Dit is een technische inventarisatie op basis van officiële bronnen, gecontroleerd op **24 november 2026**. Waar staat ‘onbekend’ of ‘te controleren’, is aanvullende informatie of advies van een jurist nodig. De site is daarmee **niet** “juridisch volledig waterdicht” verklaard.

Bronnen (allemaal officieel): ACM, Autoriteit Persoonsgegevens (AP), Ondernemersplein/KVK, wetten.overheid.nl, NVWA, Stichting Reclame Code (RvA). EUR-Lex was tijdens het onderzoek niet bereikbaar; EU-regels zijn gecontroleerd via de Nederlandse uitvoeringsregels.

## Technische maatregelen (gedaan)

- Geen trackers, geen Google Fonts, geen embeds van Google; lettertypes zelf gehost.
- Content-Security-Policy die alleen de benodigde domeinen toestaat (`dist/_headers`).
- Externe scripts (Guestplan, Untappd) pas na een handeling van de bezoeker.
- Werkend toestemmingsmechanisme klaar voor toekomstige tracking (uit), met gelijkwaardige knoppen ‘Alles weigeren’ en ‘Alles accepteren’, intrekken via de voet.
- Conceptteksten (privacy, cookies, toegankelijkheid) zijn op de site **zichtbaar gemarkeerd als concept**.
